# 投資總覽

iPhone／iPad 用的投資總覽 App（PWA）。打開時會透過 Google Apps Script 讀取私人試算表「Investment Auto」的最新數據，畫成總覽圖表和各投資項目頁面。

- 網址：https://pv7999u7-prog.github.io/invest-dashboard/
- 這個 repo 只有程式碼，**沒有任何財務資料**。資料只會在輸入密碼後，從試算表直接傳到你的裝置上。

## 第一次設定

1. 打開試算表 → **擴充功能 → Apps Script**
2. 把 [`apps-script/Code.gs`](apps-script/Code.gs) 整段貼上，把第 6 行的 `KEY` 改成你自己的密碼，存檔
3. **部署 → 新增部署作業 → 類型選「網頁應用程式」**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   - 第一次部署會要求授權讀取試算表，按允許
4. 複製部署後的網址（`https://script.google.com/macros/s/…/exec`）
5. 在 iPhone Safari 打開上面的 App 網址 → 分享 → **加入主畫面**
6. 從主畫面打開 App，填入網址和密碼

> iOS 主畫面的 App 和 Safari 分開儲存資料，請在「加入主畫面後的 App」裡填設定。

## 頁面

| 分頁 | 內容 |
|---|---|
| 總覽 | 總現值、累計獲利、IRR、距高點、今年實際獲利、年度目標、資產走勢、資產配置、最近資金異動 |
| 美股 | CUBE／Firstrade 總值與 IRR、個股報酬率圖、持股明細、最近交易 |
| 台股 | 總值與 IRR、個股報酬率、持股比重、持股明細、最近交易 |
| 加密貨幣 | 幣別比重、持有、存放位置、已兌現、放貸 |
| 更多 | 小孩帳戶、我的定期定額、長期計畫、固定支出、房產、里程碑、設定 |

右上角的眼睛可以隱藏所有金額（只留百分比），在別人面前打開時使用。

## 更新程式

- 改了 `app.js`／`index.html` 後，把 `sw.js` 的 `VERSION` 加一號再推送。
- 試算表版面大改時，調整 `Code.gs` 的 `RANGES` 和 `app.js` 裡對應的解析函式。改了 `Code.gs` 要到 Apps Script **管理部署作業 → 編輯 → 版本選「新版本」** 才會生效。
